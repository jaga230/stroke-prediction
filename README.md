# Clinical Decision Support System for Stroke Prediction using Machine Learning

## Project Overview
This project predicts whether a patient is at high risk of a stroke using Machine Learning techniques. It is built as a full-stack Clinical Decision Support System (CDSS) featuring an automated triage pipeline and a doctor-override mechanism.

## Technologies Used
* Python
* Pandas
* NumPy
* Scikit-learn
* Flask (REST API)
* React.js (Frontend)
* MongoDB Atlas (Database)

## Machine Learning Concepts Used
* Supervised Learning
* Classification
* Random Forest Classifier
* SMOTE (Synthetic Minority Over-sampling Technique)
* Feature Scaling & Data Preprocessing

## Output
The model predicts whether a patient is at high or low risk for a stroke based on clinical biometric details (such as Age, BMI, Average Glucose Level, and Hypertension history).
